데이터 활용 명세서

제주 사장님 상권비서가 쓰는 데이터의 출처·기간·컬럼·전처리·이용조건·반출 기준

요약 — 센터 필수 데이터(카드 이용 현황 1-08·1-12·1-14)가 결론의 중심이고, 제주데이터허브 공개 데이터 2계열(597, 관광지 및 상업지구)로 먼저 답하고 방향을 교차 확인합니다. 센터 카드 데이터에 없는 경쟁(가게 수)·최근 방문객·인구는 공공데이터포털 실제 값으로 채웁니다. 센터 데이터는 센터 PC 안에서만 분석하고, 외부 AI로 보내지 않으며, 반출은 응용집계·PNG로만 만듭니다.

이 문서는 tools/build_data_spec.py가 카탈로그(catalog/*.json)와 동봉 파일(data/public)에서 자동으로 만듭니다. 이용조건은 각 데이터의 공공데이터포털 페이지 '이용허락범위' 표기(2026-11-10 확인)입니다.
