센터 직원 · 1. 설치

설치는 더블클릭 두 번 1회 · 15~20분

필요한 것

💻PC

Windows 10/11 64비트. 센터 PC(Windows 11, i7-8700, RAM 32GB)에서 동작. GPU 안 씀, 디스크 약 1GB

🐍Python 3.11 이상

python.org 설치 파일. 첫 화면의 'Add python.exe to PATH' 체크. 없으면 설치 스크립트가 winget 설치를 제안

🌐인터넷

설치 때 패키지(pypi.org)를 받음. 사용 중에는 공고 조회·AI(선택)에만

🧭브라우저

Edge 또는 Chrome(기본 설치된 것)

설치 순서

  1. 제출 zip(또는 저장소 ZIP)을 C:\JejuDataAgent처럼 쓰기 쉬운 곳에 풉니다
  2. install.bat을 더블클릭합니다가상환경을 만들고 패키지를 설치합니다(3~10분)
  3. 마지막에 운영자 PIN(숫자 6~12자리)을 정합니다PIN 원문은 저장하지 않고 해시(PBKDF2)만 저장합니다
  4. 바탕화면에 제주 사장님 상권비서 바로가기가 생깁니다
  5. 바로가기(또는 run.bat)를 실행하면 브라우저가 열립니다검은 창을 닫으면 종료됩니다
💡

브라우저가 열리지 않으면 검은 창에 적힌 주소(보통 http://localhost:8501)를 주소창에 넣습니다. 8501이 쓰이고 있으면 8502, 8503… 순서로 비어 있는 번호를 씁니다.

📦 자동 설치되는 패키지

streamlit, pandas, numpy, openpyxl, python-docx, matplotlib — requirements.txt에 버전 고정. 앱 폴더의 가상환경(.venv)에만 설치되어 PC 전체에 영향이 없습니다

🔒 PIN 관련 파일

set_pin.bat PIN 정하기·바꾸기
reset_operator.bat PIN을 잊었을 때 — PIN과 저장된 키를 함께 지움(다시 정해야 함)

📞 방문 예약 상담 때

  1. 운영자 화면의 방문 예약 준비(직원용)에 방문자의 질문과 활용 목적을 넣습니다전화·이용 신청 상담 때
  2. 필요한 센터 표·기간 목록과 방문자에게 보낼 안내문이 나옵니다
  3. 그 표를 미리 받아 미리 넣어 둔 데이터 폴더에 두면, 방문자는 데이터 단계를 건너뜁니다

📤 반출 접수 때

방문자가 반출 신청 묶음 만들기로 만든 zip에는 이것만 들어 있습니다.

📄 분석 보고서(DOCX)🖼️ 근거 그림(PNG)📄 사업계획서 근거팩(DOCX)📝 반출 신청 문구(출처·기간·활용 사유)
원본 데이터조회 결과미리보기 표

앱이 미리 점검한 결과(응용집계·PNG·출처 기재)도 묶음에 적혀 있으니, 직원은 센터 반출 절차에 따라 확인만 하면 됩니다.

모두

결과 읽는 법

실제

공개 데이터(실제 값). 데이터허브·공공데이터포털에서 받은 값으로, 카드마다 단위(시·지구)와 기간을 적습니다

센터

센터 카드 데이터(동네×업종 단위)로 계산한 값. 센터에서만 나오는 수치입니다

체험 / 가상

센터 데이터 자리에 명세서 형식의 가상 데이터를 넣은 시연용 값. 숫자에 의미가 없고, 보고서·그림에도 '가상'이 찍힙니다

판정 안 함 · 보류

데이터가 없거나 부족하면(표본 30행 미만, 12개월 미만 등) 결론을 내지 않습니다

추정

질문 동네와 가장 가까운 지구 유형 대응, 지원사업 자격·신청 방법 분류처럼 원자료에 없는 연결

재현 번호

R-날짜-지문. 같은 데이터·같은 질문이면 같은 결론. 보고서의 '다음 방문 때 이어서 하려면'에 질문·동네·업종·사용한 표가 적힙니다

AI 도움 켜짐 · %

AI가 질문 해석·자격 대조를 도울 때. 결론과 판정은 AI가 아니라 공개 규칙이 만듭니다

제약사항

  • 실제 센터 CSV로는 아직 검증하지 못했습니다(명세서 기반 가상 데이터와 실제 공개 데이터로 검증). 컬럼이 명세서와 다르면 화면이 안내합니다.
  • 판정 기준점은 공개 데이터 597(2016~2018)로 잡은 잠정치입니다. 센터 실데이터로 다시 점검할 예정입니다.
  • 카드 데이터는 비씨카드 결제 기준이라 매출 전체가 아닙니다. 비율·순위로 해석합니다.
  • 공개 데이터는 시·지구 단위이고 기간이 과거(597 2016~2018, 지구 2016~2017)이거나 방문자 수(매출 아님)입니다.
  • 지원사업 자격·신청 방법은 추정입니다. 신청 전 공고문을 꼭 확인합니다.
  • 센터 데이터 조회 사이트 주소가 공개되지 않아, 표별 바로가기는 운영자가 한 번 등록해야 생깁니다.
  • 센터 데이터와 분석 결과는 외부 AI로 보내지 않습니다. AI에는 질문 문장과 지원사업 공고문·입력한 조건만 보냅니다.

키가 없음. 그대로 써도 모든 기능 동작. AI를 쓰려면 운영자 설정에서 키 입력

"AI 키가 맞지 않거나 만료되었습니다"

운영자 설정에서 새 키로 바꾸기(공급자 사이트에서 만료일 확인)

"이번 달 AI 사용량을 100% 모두 써서…"

월 한도 도달. 다음 달 1일에 0%부터. 필요하면 운영자 설정의 월 한도 조정

지원사업: "실시간 조회 실패, 저장본 사용"

인터넷 또는 공공데이터포털 키 문제. 마지막 저장본(날짜 표시)으로 계속 동작

운영자 PIN을 잊음 · 잠김

잠김은 표시된 시간만큼 기다림. 잊었으면 reset_operator.bat(키도 지워짐) → set_pin.bat
