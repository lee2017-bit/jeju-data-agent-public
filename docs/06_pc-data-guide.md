# PC에서 받아야 하는 공개 데이터 안내 (2026-11-04)

결과 화면을 가상 데이터 대신 **실제 공개 데이터로 최대한 채우기** 위한 정리다. 이미 자동으로 넣은 것과, 사용자가 PC나 계정에서 한 번 해 줘야 하는 것을 나눈다.

|---|---|---|---|
| 제주데이터허브 597 내국인 관광객 카드 이용 | 완료(앱에 동봉) | 없음 | – |
| 소상공인 상가(상권)정보 — 동네·업종별 가게 수(2026.09) | **완료(앱에 동봉, 이번에 추가)** | 없음 | – |
| 제주데이터허브 '관광지 및 상업지구' 카드 5종 + 테마별 카드 1종 | **완료(11/4 PC에서 받아 첨부 → 동봉, 2016.09~2017.11)** | 없음 | – |

## 왜 개발 환경에서 직접 받을 수 없나

1. **제주데이터허브는 클라우드 IP를 막는다.** `jejudatahub.net`과 API 주소 `open.jejudatahub.net`은 해외·클라우드 IP를 웹방화벽으로 차단한다. 개발 환경(클라우드)에서는 접속 자체가 거절된다. 프록시 등으로 우회하면 이용약관과 대회 규칙을 어길 위험이 있어 하지 않는다. 집이나 센터 PC(국내 인터넷)에서는 바로 된다. 597도 이 방법으로 받았다.
2. **공공데이터포털 API는 '활용신청한 API'에만 키가 열린다.** 지금 키로 관광공사 방문자 수 API와 행안부 인구 API를 호출하면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(등록되지 않은 서비스키)가 돌아온다(2026-11-03 실측). 활용신청은 본인 계정으로 로그인해야만 할 수 있다. 신청만 해 주면 받기는 개발 환경에서 한다. PC는 필요 없다.
3. 상가정보는 키가 필요 없는 '파일 데이터'라 개발 환경에서 바로 받아 이미 넣었다. 분기마다 새로 받을 때는 `python -m jeju_agent.stores update`를 쓴다.

## A. 데이터허브 6종 받기 (PC, 약 10분)

### 받을 데이터

| # | 제주데이터허브 데이터 이름(검색어) | 단위 | 앱에서 채울 칸 |
|---|---|---|---|
| 1 | 관광지 및 상업지구 요일별 카드 데이터 | 지구 × 요일 × 월 | 요일 카드(실제 값) |
| 2 | 관광지 및 상업지구 시간대별 카드 데이터 | 지구 × 시간대(오전·점심·오후·저녁·밤) × 월 | 시간대 카드(실제 값) |
| 3 | 관광지 및 상업지구 업종별 카드 데이터 | 지구 × 업종 × 관광객구분 × 월 | 지구별 업종 매출 구성 |
| 4 | 관광지 및 상업지구 이용자 유형별 카드 데이터 | 지구 × 법인·도민·내국인관광객·중국인관광객 × 월 | 손님 구성(지구 단위) |
| 5 | 관광지 및 상업지구 연령대, 성별 카드 데이터 | 지구 × 연령대 × 성별 × 월 | 손님 연령·성별 |
| 6 | 내국인 관광객 테마별 카드 이용 데이터 | 테마 × 월 | 1인당·1건당 이용금액 |

- '지구'는 상업지, 내국인 주요관광지, 중국인 주요관광지, 제주시 구도심, 서귀포시 구도심이다.
- 참고문서 예시 기간은 2016.01~2019.02이다. 정확한 기간은 받아 보면 확인된다.
- API 주소는 공공데이터포털에 올라 있는 각 데이터의 참고문서(데이터셋 15094889~15094893, 15094859)에서 확인했고, 스크립트에 넣어 두었다.

### 순서

1. PC에서 [jejudatahub.net](https://jejudatahub.net)에 로그인한다(597을 받을 때 쓴 계정).
2. 위 표의 이름으로 하나씩 검색한다. 데이터 상세 페이지에서 **[프로젝트에 담기]**를 누르고, 597을 담았던 프로젝트를 고른다. 6개 모두 반복한다.
3. **마이페이지 → 프로젝트 관리 → 그 프로젝트**에서 프로젝트키를 **복사(Ctrl+C)**한다.
4. 저장소 폴더의 `tools\windows\get_hub.bat`을 더블클릭한다. "클립보드에 복사된 키를 쓸까요?"가 나오면 Enter를 누른다.
5. 6종을 차례로 받는다(1종에 수십 초). 끝나면 같은 폴더에 **`허브_카드6종_YYYYMMDD.zip`**이 생긴다. **이 파일 하나를 채팅에 첨부**하면 된다.

- 키는 화면 입력에만 쓰이고, 파일이나 zip 안에는 들어가지 않는다.
- 저장소가 PC에 없다면: GitHub 저장소 페이지 → **Code → Download ZIP** → 압축을 풀고 `tools\windows\get_hub.bat`을 실행한다.

### 막히면

| 화면에 보이는 것 | 원인과 해결 |
|---|---|
| `실패: ... (401)` 또는 `(403)` | 그 데이터를 프로젝트에 담지 않았거나 키가 다르다. 2~3단계를 다시 확인한다. |
| `실패: 받은 행이 0개` | 기간이 맞지 않는다. PowerShell에서 `.\get_hub.ps1 -Start 201601 -End 201912`처럼 기간을 줄여 다시 실행한다. |
| 일부만 받아짐 | 받아진 것만 zip에 들어간다. 그대로 첨부해 주면 되고, 못 받은 것은 이름을 알려 주면 된다. |
| 창이 바로 닫히거나 보안 경고 | 반드시 `.bat`을 더블클릭한다(실행 정책을 이 실행에만 풀어 준다). |
| API가 계속 안 됨 | 각 데이터 상세 페이지에 [파일 다운로드]가 있으면 CSV로 받아 첨부해도 된다. |

## B. (선택) 공공데이터포털 활용신청 — 신청만, 받기는 개발 환경에서

| # | 데이터 | 주소 | 앱에서 채울 칸 |
|---|---|---|---|
| B-1 | 한국관광공사_빅데이터_지역별 방문자수_GW | https://www.data.go.kr/data/15101972/openapi.do | 제주시·서귀포시 **최근** 일별 방문자 수(현지인·외지인·외국인) → 최근 계절·요일 흐름. 597(2016~2018)보다 새롭다 |
| B-2 | 행정안전부_법정동별(행정동 통반단위) 주민등록 인구 및 세대현황 | https://www.data.go.kr/data/15108071/openapi.do | 동네 인구 → '도민 1,000명당 같은 업종 가게 수'(도민 단골 기반) |

### 순서

1. [data.go.kr](https://www.data.go.kr)에 로그인한다. 개발 환경에 넣어 둔 공공데이터포털 키와 **같은 계정**이어야 한다.
2. 위 주소를 열고 **[활용신청]**을 누른다.
3. 활용목적은 '웹 사이트 개발'(또는 '기타')을 고른다. 내용에는 "제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품작 — 공공데이터 분석"을 적고, 이용허락범위에 동의한 뒤 신청한다.
4. 개발계정은 보통 바로 자동 승인된다. 다만 키가 실제로 열리기까지 1~2시간 걸릴 수 있다.
5. 신청했다고 채팅에 알려 주면, 개발 환경에서 바로 받아 화면에 넣는다. 새 키를 붙여 넣을 필요는 없다.

## 받은 뒤 바뀌는 것

- **체험 화면의 요일·시간대 카드**: 가상 값 대신 실제 지구 단위 값으로 바뀐다. 예: '관광지형은 주말형, 구도심은 평일형'. 센터 데이터는 여기서 더 나아가 동네 × 업종 단위까지 보여 준다. 이 차이가 '센터에 와야 하는 이유'로 그대로 쓰인다.
- **손님 구성**: 597(시 단위)에 더해 지구 단위로 법인·도민·관광객·중국인 비중을 본다.
- **최근 흐름(B-1)**: 2016~2018 자료만 있던 계절 판단에 최근 방문객 흐름을 더한다.
- 모두 실제 값이라 화면·보고서에 '공개 데이터(실제 값)'로 표시하고, 출처를 자동으로 적는다.
