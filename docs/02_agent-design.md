# Agent 설계 v0.1 (2026-11-02)

전제: `docs/01_problem-definition.md` v0.2. 원칙은 **키 없이도 끝까지 도는 흐름을 먼저 완성하고, LLM은 그 위에 얹는다.**

## 흐름 (화면 4단계)
1. **무엇이 궁금하세요?**
   - 목적 선택: 창업·입지 / 우리 가게 / 지역 현안 / 공부
   - 예시 질문 버튼 또는 자유 입력 → 슬롯 추출: 지역, 업종, 기간, 대상(관광객/도민), 지표
2. **이 데이터를 받아 오세요**
   - 데이터 목록(`catalog/center_catalog.json`, 표 71종)에서 표 추천
   - 센터 시스템 추출 조건 안내(표 번호, 필요한 컬럼, 필터, 기간). SQL 필요 여부는 확인 중.
3. **파일 넣기 → 분석**
   - CSV 자동 판별(컬럼 일치도로 표 번호 추정), 인코딩(UTF-8/CP949), 'NA'는 값으로 유지
   - 검증된 결정적 분석 도구만 사용: 비중, 순위, 월별 추세·증감, 요일·시간대 패턴, 제주 평균 대비 비교
   - 자동 검산: 부분합=전체, 기간 누락, 표본 수 부족 경고
4. **결과와 반출**
   - 차트(PNG), 한 장 요약(사업계획서에 붙일 형태), 근거(데이터명·기간), 한계
   - 반출 패키지: 10 미만 처리(`jeju_agent/export_policy.py`), PNG·보고서, 반출 신청서 초안

## LLM 역할 (선택)
| 단계 | LLM 사용 시 | 키 없을 때 |
|---|---|---|
| 질문 해석 | 자유 문장 → 슬롯 | 선택형 질문(드롭다운) |
| 해설 문장 | 응용집계(비율·순위·증감)만 받아 쉬운 말로 | 문장 틀(템플릿) |

- 원본 행·단순집계 수치는 외부로 보내지 않는다. 보내는 것: 질문, 표 스키마, 응용집계.
- 운영자 설정: API 키 입력, 월 비용 상한, 사용 기록.

## 알려진 데이터 함정
- 카드는 법정동(73), 유동인구는 행정동(43) → 결합하려면 법정동–행정동 대응표 필요
- 'NA'는 명세서상 실제 값(예: 법인 카드 연령) → `keep_default_na=False`
- 세분화된 카드 데이터는 값의 대부분이 10 미만 → 동·업종 단위로 묶거나 비율로 변환해야 반출 가능
