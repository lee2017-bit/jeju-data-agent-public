# 제주 사장님 상권비서 (jeju-data-agent)

제주에서 가게를 열거나 꾸려 가는 **사장님**이 제주빅데이터센터에서 **코딩 없이** 묻는 상권 질문 — *관광객 장사일까 도민 장사일까, 언제 붐빌까, 어디가 나을까* — 에 센터 카드 데이터로 답하고, 사업계획서에 넣을 **근거(차트·해설·출처)**와 **반출 가능한 결과물**까지 챙겨 주는 AI Agent입니다. 보고서·논문용 문장도 함께 만들어 기관·연구자도 쓸 수 있습니다.
「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 출품작.

**설치 없이 써 보기(공개 데모)**: https://jeju-data-agent.streamlit.app — 센터 PC 설치본과 같은 프로그램입니다(센터 데이터 자리는 체험용 가상 데이터, 공개 데이터는 실제 값). 12시간 접속이 없으면 잠들어, 첫 화면의 "Yes, get this app back up!"을 누르면 1분쯤 뒤 열립니다. 데모는 Streamlit Community Cloud(무료)에 올렸고, AI 키는 호스팅의 비밀값(Secrets)에만 있으며 저장소·제출물에는 없습니다.

## 무엇을 하나 (화면 4단계)
1. **질문** — 목적(가게 열기·사업계획서 / 가게 운영 / 현황자료·보고서 / 논문·연구)을 고르고 일상어로 묻습니다. 예: "카페 하려는데 애월이랑 한림 중 어디가 좋을까?" Agent가 이해한 동네·업종과 분석 순서(손님 → 계절 → 다른 동네 → 요일 → 시간대)를 먼저 보여 주고, 틀리면 고칠 수 있습니다.
2. **데이터 준비** — 필요한 센터 데이터(명세서 v12 표 71종 중)와 받는 방법을 체크리스트로 안내합니다. 내려받기 폴더를 3초마다 살펴 맞는 CSV가 생기면 저절로 넣고, **모두 준비되면 자동으로 결과로 넘어갑니다.** 공개 데이터(제주데이터허브 597)는 앱에 동봉돼 있어 할 일이 없습니다.
3. **결과(결론 먼저)** — 체험 모드에서는 맨 위에 **실제 공개 데이터만으로 본 답**(제주데이터허브 597 + 상가정보 가게 수)을 먼저 보여 주고, 그 아래 센터 데이터를 넣었을 때의 모습(가상 예시)을 보여 줍니다. 맨 위에 질문에 대한 **판정 문장**(예: "애월읍 카페는 관광객이 더 많고, 계절을 조금 타며, 주말·점심에 몰리는 장사입니다"), 핵심 수치 3개, **그래서 할 일 3가지**를 보여 줍니다. 그 아래 결론형 근거 카드(손님 구성·월별 흐름·요일·시간대·다른 동네·**경쟁(가게 수, 실제 값)**)와 **공개 데이터 교차 확인** 카드가 이어집니다.
4. **가져가기** — 먼저 **내가 신청해 볼 만한 지원사업**(K-Startup·기업마당 모집 중 공고 1,500건 안팎에서 상태·나이대·위치·업종으로 거르고 '지금 신청 / 가게 연 뒤 / 조건 확인'으로 묶음, 거른 이유 공개)을 보고 근거팩에 넣을 공고를 고릅니다. 그다음 활용 사유를 확인하고 반출 신청 묶음(보고서 DOCX·그림 PNG·사업계획서용 **지원사업 근거팩**·신청서 문구)을 한 번에 만듭니다. 지원사업 판정은 기본이 규칙(PC 안에서, 같은 조건이면 같은 답)이고, AI로 공고문과 자격을 대조하는 것은 버튼을 누를 때만 합니다.

판정은 AI가 아니라 **공개된 규칙표**로 코드가 합니다(같은 데이터면 늘 같은 결론). 화면의 [판정 기준 보기]와 보고서 부록에 그대로 싣습니다. 체험 데이터로 본 예: "[체험] 애월읍 카페는 관광객이 더 많고, 계절을 조금 타며, 주말·점심에 몰리는 장사입니다." (관광객 손님 몫 60%, 성수기 ÷ 비수기 1.6배, 카페 매출 4위/71곳 — 체험 수치는 테스트로 고정)

| 항목 | 기준(요약) | 기준점 |
|---|---|---|
| 손님 구성 | 관광객 매출 비중 65% 이상 '뚜렷한 관광객 장사', 55~65 '관광객 장사', 45~55 '반반', 35~45 '도민 단골 장사', 35 미만 '뚜렷한 도민 단골 장사' | 597 실측: 읍면 식당·카페 64.6~65.0%, 제주시 도심 29.3% |
| 계절 | 가장 많은 달 ÷ 가장 적은 달 2.0배 이상 '영향 큼', 1.5~2.0 '있음', 미만 '고른 편'. 평소 달=100 지수 120 이상 성수기, 80 미만 비수기 | 597 실측: 관광객 2.3배, 도민 1.5배 |
| 경쟁(가게 수) | 같은 업종 가게 수 동네 순위 3위 안 '손꼽히게 많음', 10위 안 '많음'. 센터 매출 몫 ÷ 가게 몫(가게 하나당 매출 지수) 1.2 이상 '손님 넉넉', 0.8 미만 '가게가 많은 편' | 상가정보 실측(2026.09): 애월읍 카페 221곳, 제주 1위 |
| 시장 크기 | 같은 업종 제주 전체 매출 중 그 동네 몫의 순위(3위 안 '손꼽히는 큰 시장' …) | 가게 수가 없어 경쟁은 판정하지 않음 |
| 요일 | 토+일 비중 33% 이상 '주말형', 25% 이하 '평일형' | 고르게 나뉘면 28.6%, 공휴일 중복 제외 |
| 시간대 | 시간대 길이가 달라(점심 3시간, 밤 9시간) 1시간당 비중으로 비교 | 명세서 [참고4] |

## 빠른 시작 (Windows 10/11)
1. **Python 3.11 이상** 설치 — https://www.python.org/downloads/windows/ (설치 첫 화면의 *Add python.exe to PATH* 체크). 없으면 설치 스크립트가 winget 설치를 제안합니다.
2. 이 폴더에서 **`install.bat`** 더블클릭 → 가상환경(.venv)을 만들고 패키지를 설치합니다(3~10분, 인터넷 필요). 바탕화면에 바로가기가 생깁니다.
   마지막에 **운영자 PIN**(숫자 6~12자리)을 정합니다. 나중에 정하거나 바꾸려면 `set_pin.bat`(현재 PIN 확인), 잊었으면 `reset_operator.bat`(PIN과 저장된 키를 함께 지움).
3. **`run.bat`**(또는 바탕화면 *제주 사장님 상권비서*) 더블클릭 → 브라우저가 열립니다. 검은 창을 닫으면 종료됩니다.
4. 센터 밖에서 바로 보려면 첫 화면의 **예시 결과 바로 보기**(체험 데이터, 약 3초).

운영자 설정(모드·데이터 폴더·표별 바로가기·API 키·AI 사용 금액)은 방문자 화면에 보이지 않습니다. 주소창에 `http://localhost:8501/admin`을 입력하고 PIN을 넣어야 열리며, 15분 동안 쓰지 않으면 잠깁니다. PIN은 해시(PBKDF2)로만 저장하고, PIN을 정하기 전에는 운영자 설정이 열리지 않습니다. 5번 틀리면 5분·15분·60분으로 잠금이 길어지고, 앱을 다시 켜도 유지됩니다. 키는 같은 PC 계정이면 설정 파일에서 볼 수 있으므로, AI 키는 공급자 쪽 **프로젝트 월 예산 한도**를 걸어 쓰고 정기적으로 바꾸기를 권합니다.

수동 설치(모든 OS):
```bash
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 키와 환경변수 (모두 선택)
키가 없어도 기본 기능(규칙 해석·분석·보고서·반출 패키지)은 모두 동작합니다. 키는 **운영자 페이지(/admin)**에서 넣거나 `.env.example`을 `.env`로 복사해 채웁니다. 키는 그 PC의 `config/local_settings.json` 또는 `.env`에만 저장되며 저장소·제출물에 넣지 않습니다.

| 변수 | 용도 | 없을 때 |
|---|---|---|
| `OPENAI_API_KEY` (+ `OPENAI_BASE_URL`) | 자유 질문 해석, 지원사업 자격 확인(기본 모델 gpt-6-luna, OpenAI 호환 API 가능) | 규칙 해석·규칙 판정 |
| `JEJUDATAHUB_APP_KEY` | 제주데이터허브 Open API로 공개 데이터 바로 받기 | 받아 둔 CSV를 넣어 사용 |
| `DATA_GO_KR_KEY` | 공공데이터포털 K-Startup·기업마당 지원사업 공고, 관광공사 방문자 수·행안부 인구 새로 받기 | 지원사업은 마지막 저장본, 방문자 수·인구는 동봉 파일 |

AI 모델은 **gpt-6-luna 하나만** 씁니다. 상위 모델 gpt-6-sol(단가 20배)과 실측 비교한 결과 질문 해석 15문항 완전 정답이 13 대 13으로 같았고, 지원사업 자격 판정 36건 중 30건이 일치했습니다(갈린 6건 중 5건은 sol이 '확인 필요'로 더 조심스러웠을 뿐). 결론 판정은 원래 규칙이라 모델과 무관합니다. 실측 비용은 질문 해석 1번 약 $0.0001, 자격 판정 1번 약 $0.001입니다. 2026-11-10 다시 잰 질문 해석 15문항은 규칙만 10, AI를 더하면 3회 모두 15였습니다(`tools/bench_parse.py`, 결과 `docs/submission/results/parse_bench.json`).

AI 비용 관리: 한도는 **이번 달 사용 금액 $10 하나**뿐입니다(사람별·하루 횟수 제한 없음). 호출마다 토큰·비용을 `data/usage_log.jsonl`에 기록하고, 방문자 화면에는 금액 대신 **한도 대비 사용량(%)**만 보여 줍니다(예: "AI 도움 켜짐 · 이번 달 사용량 37%"). 100%가 되면 조용히 바꾸지 않고 화면 위에 **"AI 꺼짐 — 이번 달 AI 사용량을 100% 모두 써서, 지금부터는 정해진 규칙으로만 답합니다"**와 그 영향(자유로운 말투 해석이 약해짐, 결론 판정은 그대로)을 알립니다. 다음 달 1일에 0%부터 다시 셉니다. 금액은 운영자 페이지에서만 볼 수 있습니다.

공개 데모: AI 키는 데모 전용 프로젝트 키를 호스팅의 비밀값(secrets)에만 넣고, 공급자 쪽 프로젝트 예산 한도도 $10로 겁니다(무료 호스팅은 앱이 다시 시작되면 사용 기록 파일이 지워질 수 있어, 앱의 % 표시가 0부터 다시 셀 수 있음 — 실제 비용을 막는 것은 공급자 쪽 한도). `JEJU_AGENT_DEMO=1`이면 운영자 페이지를 닫습니다.

## 데이터
- **제주빅데이터센터 데이터(필수 데이터)**: `reference/center-data-spec_v12_2026-01-28.xlsx`(데이터 명세서 v12)를 읽어 `catalog/center_catalog.json`(표 71종, 컬럼·코드표)으로 만들어 씁니다. 센터 데이터는 센터 PC 안에서 CSV로 내려받아 넣습니다(Agent가 센터 시스템에 직접 접속하지 않음).
- **제주데이터허브 공개 데이터(필수 데이터)**: 597 「내국인 관광객 지역·업종·성별·연령대별 카드 이용 데이터」. Open API로 받은 전체 기간(2016.09~2018.12, 19,573행)을 `data/public/`에 동봉해 시작할 때 자동으로 씁니다. 결과 화면에서 센터 결과와 **같은 방향인지 교차 확인**하고, 시·도심/읍면 4그룹 비교로 '이 동네만의 특징인지, 읍면이면 어디나 그런지'를 가립니다. 새로 받으려면 운영자 페이지 또는 `tools/windows/get_597.bat`. 데이터허브의 '관광지 및 상업지구' 카드 5종 등은 클라우드에서 막혀 PC에서 `tools/windows/get_hub.bat`으로 받습니다(안내: `docs/06_pc-data-guide.md`).
- **소상공인 상가(상권)정보(공개, 실제 값)**: 2026년 9월 말 기준 제주 59,101곳을 동네·업종별 가게 수로 줄여 `data/public/`에 동봉합니다. 센터 카드 데이터에 없는 **경쟁(같은 업종 가게 수)**을 실제 값으로 판정하고, 센터 매출 몫과 합쳐 '가게 하나당 매출이 평균보다 큰지'까지 봅니다. 새로 받기: `python -m jeju_agent.stores update`(키 필요 없음).
- **관광공사 방문자 수·행안부 법정동 인구·데이터허브 관광지 및 상업지구(공개, 실제 값)**: 최근 1년 제주시·서귀포시 외지인 방문자 흐름(2025.10~2026.09), 도민 1,000명당 같은 업종 가게 수(2026.10), 지구 유형별 요일·시간대·손님 구성(2016.09~2017.11)을 카드로 보여 줍니다. 이용조건은 모두 공공데이터포털 표기 '이용허락범위 제한 없음'(자세히: `docs/submission/데이터_활용_명세서.pdf`).
- **가상(체험) 데이터**: 센터 밖 시연·테스트용. 명세서와 컬럼·코드값이 같고 수치는 의미 없습니다. 파이썬 계산으로 만들며(AI 사용 안 함) 표 3개를 1~2초에 만듭니다. 계절 모양은 597 실측(도심/읍면 × 관광객/도민 달별 패턴)을 따릅니다. 화면·보고서·그림에 '가상'을 표시하고, 실제 데이터 결과와 구분합니다. `python -m jeju_agent.synth 1-08 --period 202505-202604`
- **반출 정책 준수**: `reference/center-export-policy_2026-09-01.pdf`를 코드로 옮겼습니다(`jeju_agent/export_policy.py`). 반출용 결과는 비중·순위·지수 같은 응용집계와 PNG 그림만 쓰고, 단순집계 10 미만은 처리하며, 원본·데이터 미리보기는 넣지 않습니다.

## 오류·제약사항 (알려진 것)
- 실제 센터 CSV로는 아직 검증하지 못했습니다(명세서 기반 가상 데이터와 실제 공개 데이터 597로 검증). 컬럼이 명세서와 다르면 화면에 안내합니다.
- 판정 기준점은 공개 데이터 597(2016~2018)로 잡은 잠정치입니다. 센터 실데이터로 다시 점검할 예정입니다.
- 카드 데이터는 비씨카드 결제 기준이라 실제 매출 전체가 아닙니다. 공개 데이터 597은 시 단위·업종 9종까지만 나뉩니다.
- 카드(법정동)와 유동인구(행정동)는 지역 단위가 달라 아직 결합 분석을 하지 않습니다.
- 지원사업의 신청 방법(방문·온라인 등)은 공고 문장에서 자동 분류한 추정이므로 공고문을 확인해야 합니다.
- 센터 데이터를 조회하는 사이트 주소는 공개되지 않아, 표별 바로가기 링크는 운영자 설정에서 한 번 입력하는 방식입니다.
- 결론 문장과 판정은 규칙 코드가 만들고 AI는 쓰지 않습니다. AI 해석의 지명 대응은 내장 제주 지명 사전으로 확인합니다.
- 지원사업 자격 판정(AI·규칙)은 추정입니다. 신청 전에 공고문을 꼭 확인해야 합니다.
